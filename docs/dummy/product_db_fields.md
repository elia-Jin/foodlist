# 상품 DB 필드 정의 (실습용)

- 대상: `docs/dummy/products/` 가상 상품 10건
- 데이터 파일: `docs/dummy/product_db.xlsx` (시트: 상품 · 배송정책 · 필드정의)
- 모든 값은 가상 데이터이므로 실습 밖으로 옮기지 않는다

## 상품 시트 (한 행이 상품 1개)

| 필드명 | 영문 키(DB 이전용) | 예시 (P-0113) | 비고 |
|---|---|---|---|
| 상품코드 | product_id | P-0113 | 기본 키 |
| 상품명 | name | 대구사과칩 | |
| 분류 | category | 가공식품 | 신선/가공/냉동 등. 문서에 없음 → 직접 입력 |
| 원산지 | origin | 대구 팔공산 | |
| 원재료 | ingredients | 사과 100% | |
| 용량 | net_amount | 60 | 숫자만 |
| 단위 | unit | g | g / kg / ml |
| 입수 | pack_count | | 30포, 20개 등 |
| 가격 | price | 4900 | 숫자만, 원 단위 |
| 상품설명 | description | 저온에서 말린 과자 | |
| 판매기간 | sale_period | | "4~7월 한정" 같은 경우 |
| 보관방식 | storage_type | 상온 | 상온/냉장/냉동 |
| 개봉전유통기한 | shelf_life_unopened | 6개월 | 신선 농산물은 수령 후 보관 기간 |
| 개봉후섭취기한 | shelf_life_opened | 7일 | |
| 보관금지사항 | storage_warning | 냉장 금지 | 냉동 금지, 전자레인지 금지 등 |
| 보관메모 | storage_note | 밀봉해 서늘한 곳 | 그 밖의 보관 팁 |
| 알레르기유발물질 | allergens | | 제품에 들어 있는 것 (밀, 대두 등) |
| 교차오염주의 | cross_contact | 견과류 | 생산 라인 공유로 섞일 수 있는 것 |
| 섭취주의사항 | caution | | 임산부 주의 등 |

## 배송정책 시트 (10개 상품 공통)

| 정책코드 | 항목 | 조건 | 값 |
|---|---|---|---|
| SHIP-01 | 배송비 | 주문 금액 3만원 이상 | 무료 |
| SHIP-02 | 배송비 | 주문 금액 3만원 미만 | 2,500원 |
| SHIP-03 | 배송일 | 수성구 · 달서구, 오후 2시 이전 주문 | 당일 배송 |
| SHIP-04 | 배송일 | 그 외 지역 | 익일 배송 |
| SHIP-05 | 발송요일 | 신선 식품 | 월~목 발송 |
| SHIP-06 | 발송요일 | 신선 식품, 금요일 주문 | 다음 주 월요일 발송 |

## 값 입력 규칙

- `-` = 해당 없음 (예: 개봉 개념이 없는 농산물의 개봉후섭취기한)
- `표기 없음` = 원문 문서에 정보가 없음 → 확인 필요
- 빈칸(노란색) = 분류. 문서에 없어 직접 정해야 함
